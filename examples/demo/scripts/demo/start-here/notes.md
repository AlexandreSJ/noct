# start-here

The tour. Run it from the scripts panel (`prefix` + `s`, then Enter) and read
what it prints.

It takes no parameters, so it is the simplest script in the demo: a single
`run` that only calls `printf`. Open it in an editor with `e` in the scripts
panel to see the whole thing on one screen.

When you have read the tour, open `demo-deploy` in the inspect (`prefix` + `i`)
and follow it step by step. The other demo scripts are the steps it runs.
